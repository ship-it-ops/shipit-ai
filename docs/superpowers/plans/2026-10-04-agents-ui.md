# Agents UI Implementation Plan (Milestone 1, third part: web UI)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A person can use agents from the web UI: list them, create and edit one (instructions, model and limits, tools and permissions), save drafts safely, publish with a diff, try the draft in a test panel, ask the built-in Graph assistant on the Ask page, and read any run with every tool call it made. When agent features are not set up, the AI pages say what is missing.

**Architecture:** All new UI is under `packages/web-ui/src/components/ai` and `src/lib`, on the design system (`@ship-it-ui/ui`, `@ship-it-ui/shipit`) and React Query, with no new dependency. One API client module mirrors the server's types and turns every error into a typed `AgentApiError`. Runs are followed over the server-sent stream through one hook; one transcript model and one chat component serve the test panel, Ask and the run view. The api-server gains only the tool catalog route (and a CORS fix local dev needs).

**Tech Stack:** Next.js 16 (App Router, client pages), React 19, TypeScript, `@tanstack/react-query` 5, `@ship-it-ui/ui` and `@ship-it-ui/shipit`, Vitest 4 with Testing Library and `vitest-axe` (jsdom), Fastify 5 with `@fastify/cors` 11.

**Spec:** `docs/superpowers/specs/2026-10-01-ai-agents-and-workflows-design.md` (§Web UI, §API, §Feature gating, §Built-in agent; Milestone 1). It builds on `docs/superpowers/plans/2026-10-03-agent-runner.md` (runs API, stream, built-in agent), which is implemented.

## Review Focus

Conditions the spec implies that a person will hit. Each is pinned by a test in the task that owns the code:

1. **Two people edit the same agent.** The second save is refused, not merged: the editor says so and offers a reload that discards the local changes. → Task 2 (`turns a 409 VERSION_CONFLICT into an error carrying the server revision`), Task 6 (`reports a conflicting save and reloads the other person’s version`).
2. **Agents are not set up, or stop being available.** A page shows which prerequisite is missing instead of an error, the test panel says why it cannot run, and a run that cannot start explains itself. → Task 4 (`names each missing prerequisite instead of the page`, `blocks a page that runs agents when the runner is missing`), Task 7 (`names what is missing when agents cannot run`, `explains a run that could not start`).
3. **The live stream drops, is refused, or the run ends.** The browser reconnects by itself; the client closes on `end` so a finished run is not replayed forever; a stream the browser gave up on is reported. → Task 2 (`closes itself when the run ends`, `lets the browser reconnect on a dropped connection, and reports one it gave up on`), Task 3 (`reports a stream the browser gave up on`).
4. **An answer contains markup.** Answers quote catalog data written by anyone with repository access; it reaches the page as text. → Task 3 (`shows HTML in an answer as text`).
5. **Someone who may look but not change.** The editor is read-only without `agents:write`, the test panel is not shown, Stop is only for the run's starter or an admin, and a run whose content is hidden says so. → Task 6 (`is read-only without agents:write`), Task 7 (`is not shown to someone who cannot edit the agent`), Task 8 (`says the content is hidden instead of showing an empty transcript`, `does not offer Stop to someone else, or on a finished run`).

Also pinned: saving from a browser on another origin (Task 1, `allows PUT/PATCH/DELETE from the web UI’s origin`).

## Task 1: The tool catalog route, and CORS for saves (api-server)

The editor's permission matrix needs the list of tools an agent can be granted, with each tool's service and effect: `GET /api/tools`, from the same metadata the MCP server publishes. It needs no database.

The same task fixes what the editor would otherwise hit on its first save. Local dev serves the web UI on :3000 and the API on :3001, so every call is cross-origin. `@fastify/cors` 11 allows only `GET`, `HEAD` and `POST` unless told otherwise, so a browser refuses every `PUT` (save), `PATCH` and `DELETE` (archive) at the preflight; and it hides `ETag`, which the schema and connector editors read for `If-Match`. That bug is already on `main` (production is single-origin and never sees it). Found in a browser while building this plan.

```ts
describe('CORS preflight', () => {
  let server: FastifyInstance;

  beforeAll(async () => {
    server = await createServer({ config: makeTestConfig() });
    await server.ready();
  });
  afterAll(async () => {
    await server.close();
  });

  it.each(['PUT', 'PATCH', 'DELETE'])('allows %s from the web UI’s origin', async (method) => {
    const res = await server.inject({
      method: 'OPTIONS',
      url: '/api/agents/3f0e4c1a-0000-4000-8000-000000000000',
      headers: {
        origin: 'http://localhost:3000',
        'access-control-request-method': method,
        'access-control-request-headers': 'content-type,if-match',
      },
    });
    expect(res.statusCode).toBe(204);
    expect(res.headers['access-control-allow-origin']).toBe('http://localhost:3000');

  it('lets the browser read the ETag of a cross-origin response', async () => {
    const res = await server.inject({
      method: 'GET',
      url: '/api/health',
      headers: { origin: 'http://localhost:3000' },
```

```ts
// The catalog of tools an agent can be granted (mounted /api/tools). Today
// that is the built-in graph tools, described from the MCP metadata the MCP
// server registers them with; connections (external MCP servers, the GitHub
// actions App) add theirs in Milestone 3. Nothing here is stored, so the
// route answers even when agent features are off.
import type { FastifyPluginAsync } from 'fastify';
import { MCP_TOOLS } from '@shipit-ai/mcp-server/metadata';
import { requireCapability } from '../middleware/require-auth.js';

export interface ToolInfo {
  /** '<service>.<tool>', as agent grants name it. */
  id: string;
  service: string;
  effect: 'read' | 'write' | 'delete';
  description: string;
  source: 'builtin' | 'connection' | 'agent';
}

const BUILTIN: ToolInfo[] = MCP_TOOLS.map((tool) => ({
  id: `${tool.service}.${tool.name}`,
  service: tool.service,
  effect: tool.effect,
  description: tool.description,
  source: 'builtin',
}));

const toolsRoutes: FastifyPluginAsync = async (server) => {
  server.get('/', { preHandler: requireCapability('agents:read') }, async () => ({
    tools: BUILTIN,
  }));
};

export default toolsRoutes;
```

## Task 2: The agents API client and the live run stream (web-ui)

One module for everything the AI pages ask the server: instance status, the model and tool catalogs, agents and runs. Types mirror what api-server returns. Every non-2xx answer becomes an `AgentApiError` that keeps what the UI needs to react: the server's revision on a conflict, the validation issues, the failing prerequisites. `api.ts` exports its `fetchApi` (session cookie, 401 handling) for the new module.

The live stream is a thin wrapper over the browser's `EventSource`: it closes itself on `end` (otherwise the browser reconnects and replays a finished run forever), leaves reconnecting to the browser (which sends `Last-Event-ID`), and reports only a stream the browser gave up on. jsdom has no `EventSource`, so the factory is injectable.

```ts
async function toError(res: Response): Promise<AgentApiError> {
  const body = (await res.json().catch(() => null)) as {
    error?: { code?: string; message?: string };
    issues?: ApiIssue[];
    serverRevision?: number;
    checks?: AiCheck[];
  } | null;
  return new AgentApiError(body?.error?.message ?? `Request failed (${res.status}).`, {
    status: res.status,
    code: body?.error?.code ?? `HTTP_${res.status}`,
    issues: body?.issues,
    serverRevision: body?.serverRevision,
    checks: body?.checks,
  });
}

async function request<T>(
  path: string,
  init: { method?: string; body?: unknown; ifMatch?: number } = {},
): Promise<T> {
  const headers: Record<string, string> = {};
  if (init.body !== undefined) headers['Content-Type'] = 'application/json';
  if (init.ifMatch !== undefined) headers['If-Match'] = `"${init.ifMatch}"`;
  const res = await fetchApi(`${API_URL}${path}`, {
    method: init.method ?? 'GET',
    headers,
    body: init.body === undefined ? undefined : JSON.stringify(init.body),
  });
  if (!res.ok) throw await toError(res);
  if (res.status === 204) return undefined as T;
  return (await res.json()) as T;
}

function query(params: Record<string, string | number | boolean | undefined>): string {
  const search = new URLSearchParams();
  for (const [key, value] of Object.entries(params)) {
    if (value !== undefined) search.set(key, String(value));
  }
  const text = search.toString();
  return text ? `?${text}` : '';
}
```

```ts
// Live updates for one run over server-sent events (GET /api/runs/:id/stream).
// The server sends `run` (the record) on connect and on every status change,
// `message` (id = its sequence number) as the transcript grows, and `end` once
// the run has finished. On a dropped connection the browser reconnects by
// itself and sends Last-Event-ID, so the stream resumes where it stopped.
import { runStreamUrl, type Run, type RunMessage, type RunStatus } from './agents-api';

/** The part of the browser's EventSource this module uses. */
export interface EventSourceLike {
  readyState: number;
  onerror: ((event: Event) => void) | null;
  addEventListener(type: string, listener: (event: MessageEvent) => void): void;
  close(): void;
}

export type EventSourceFactory = (
  url: string,
  init: { withCredentials: boolean },
) => EventSourceLike;

export interface RunStreamHandlers {
  onRun?(run: Run): void;
  onMessage?(message: RunMessage): void;
  onEnd?(status: RunStatus): void;
  /** The browser gave up: the stream was refused (403, 503) or is gone. */
  onError?(): void;
}

const CLOSED = 2;

const browserEventSource: EventSourceFactory = (url, init) => new EventSource(url, init);

function parse<T>(event: MessageEvent): T | null {
  try {
    return JSON.parse(String(event.data)) as T;
  } catch {
    return null;
  }
}

/** Opens the stream; the returned function closes it. */
export function openRunStream(
  runId: string,
  handlers: RunStreamHandlers,
  opts: { afterSeq?: number; createEventSource?: EventSourceFactory } = {},
): () => void {
  const url =
    runStreamUrl(runId) + (opts.afterSeq === undefined ? '' : `?afterSeq=${opts.afterSeq}`);
  const source = (opts.createEventSource ?? browserEventSource)(url, { withCredentials: true });

  source.addEventListener('run', (event) => {
    const run = parse<Run>(event);
    if (run) handlers.onRun?.(run);
  });
  source.addEventListener('message', (event) => {
    const message = parse<RunMessage>(event);
    if (message) handlers.onMessage?.(message);
  });
  source.addEventListener('end', (event) => {
    // The server ends the response after this; closing stops a reconnect.
    source.close();
    const end = parse<{ status: RunStatus }>(event);
    if (end) handlers.onEnd?.(end.status);
  });
  source.onerror = () => {
    // While reconnecting the state is CONNECTING; only CLOSED is final.
    if (source.readyState === CLOSED) handlers.onError?.();
  };

  return () => source.close();
}
```

## Task 3: The transcript: model, answer text, component and live hook (web-ui)

A stored transcript is one message per model turn and tool round.
```ts
// Turns a run's stored transcript (one message per model turn and tool round)
// into what the UI shows: a user turn per question, and one assistant turn per
// answer with its reasoning, its tool calls (each paired with its result) and
// its final text.
import type {
  RunMessage,
  ToolCall,
  ToolCallPart,
  ToolCallStatus,
  ToolResultPart,
  TranscriptMessage,
  TranscriptPart,
} from './agents-api';

export interface TranscriptToolCall {
  callId: string;
  toolId: string;
  input: unknown;
  status: ToolCallStatus;
  /** The tool's result (or error text), once there is one. */
  output?: unknown;
  /** The audit record, when the caller loaded them. */
  record?: ToolCall;
  durationMs?: number;
}

export type TranscriptItem =
  | { kind: 'user'; seq: number; text: string }
  | {
      kind: 'assistant';
      seq: number;
      reasoning: string[];
      toolCalls: TranscriptToolCall[];
      text: string;
    };

/** `graph__find_owners` → `graph.find_owners` (the runner's naming, reversed). */
export function toolIdFromModelName(name: string): string {
  return name.includes('__') ? name.replace('__', '.') : name;
}

// The runner's last-step note asks the model for an answer; it is not the person.
function isRunnerNote(message: TranscriptMessage): boolean {
  const shipit = message.providerOptions?.shipit as { kind?: string } | undefined;
  return shipit?.kind === 'step-limit-note';
}

function parts(message: TranscriptMessage): TranscriptPart[] {
  return typeof message.content === 'string'
    ? [{ type: 'text', text: message.content }]
    : message.content;
}

function textOf(message: TranscriptMessage): string {
  return parts(message)
    .filter((p): p is Extract<TranscriptPart, { type: 'text' }> => p.type === 'text')
    .map((p) => p.text)
    .join('\n');
}

function isErrorOutput(output: ToolResultPart['output']): boolean {
  return output.type === 'error-text' || output.type === 'error-json';
}

function durationOf(record: ToolCall): number | undefined {
  if (!record.startedAt || !record.finishedAt) return undefined;
  return Date.parse(record.finishedAt) - Date.parse(record.startedAt);
}

export function buildTranscript(
  messages: RunMessage[],
  records: ToolCall[] = [],
): TranscriptItem[] {
  const byCallId = new Map(records.map((r) => [r.callId, r]));
  const items: TranscriptItem[] = [];
  const calls = new Map<string, TranscriptToolCall>();
  let turn: Extract<TranscriptItem, { kind: 'assistant' }> | null = null;

  for (const { seq, content: message } of messages) {
    if (message.role === 'system') continue;
    if (message.role === 'user') {
      if (isRunnerNote(message)) continue;
      items.push({ kind: 'user', seq, text: textOf(message) });
      turn = null;
      continue;
    }
    if (message.role === 'assistant') {
      if (!turn) {
        turn = { kind: 'assistant', seq, reasoning: [], toolCalls: [], text: '' };
        items.push(turn);
      }
      for (const part of parts(message)) {
        if (part.type === 'reasoning' && part.text.trim()) turn.reasoning.push(part.text);
        if (part.type === 'text' && part.text.trim()) {
          turn.text = turn.text ? `${turn.text}\n\n${part.text}` : part.text;
        }
        if (part.type === 'tool-call') {
          const call = toCall(part, byCallId.get(part.toolCallId));
          calls.set(part.toolCallId, call);
          turn.toolCalls.push(call);
        }
      }
      continue;
    }
    // role === 'tool': results for calls made earlier in this turn.
    for (const part of parts(message)) {
      if (part.type !== 'tool-result') continue;
      const call = calls.get(part.toolCallId);
      if (!call) continue;
      call.output = part.output.value;
      if (!call.record) call.status = isErrorOutput(part.output) ? 'failed' : 'succeeded';
    }
  }
  return items;
}

function toCall(part: ToolCallPart, record: ToolCall | undefined): TranscriptToolCall {
  return {
    callId: part.toolCallId,
    toolId: record?.toolId ?? toolIdFromModelName(part.toolName),
    input: part.input,
    status: record?.status ?? 'executing',
    record,
    durationMs: record ? durationOf(record) : undefined,
  };
}

/** Adds `incoming` to `current`, in sequence order, without duplicates. */
export function mergeMessages(current: RunMessage[], incoming: RunMessage[]): RunMessage[] {
  const bySeq = new Map(current.map((m) => [m.seq, m]));
  for (const m of incoming) bySeq.set(m.seq, m);
  return [...bySeq.values()].sort((a, b) => a.seq - b.seq);
}
```

```tsx
// A model's answer, with the little Markdown models use: paragraphs, bullet
// and numbered lists, headings, **bold** and `code`. Built as React elements,
// never as HTML, so whatever the answer quotes reaches the page as text.
import { Fragment, type ReactNode } from 'react';

const INLINE = /(\*\*[^*\n]+?\*\*|`[^`\n]+`)/g;

function inline(text: string): ReactNode[] {
  return text.split(INLINE).map((piece, i) => {
    if (piece.startsWith('**') && piece.endsWith('**') && piece.length > 4) {
      return <strong key={i}>{piece.slice(2, -2)}</strong>;
    }
    if (piece.startsWith('`') && piece.endsWith('`') && piece.length > 2) {
      return (
        <code key={i} className="bg-panel-2 rounded px-1 font-mono text-[12px]">
          {piece.slice(1, -1)}
        </code>
      );
    }
    return <Fragment key={i}>{piece}</Fragment>;
  });
}

type Block =
  | { kind: 'p'; lines: string[] }
  | { kind: 'h'; text: string }
  | { kind: 'ul' | 'ol'; items: string[] };

const BULLET = /^\s*[-*]\s+(.*)$/;
const NUMBERED = /^\s*\d+[.)]\s+(.*)$/;
const HEADING = /^#{1,6}\s+(.*)$/;

function blocks(text: string): Block[] {
  const out: Block[] = [];
  for (const line of text.replace(/\r\n/g, '\n').split('\n')) {
    const last = out[out.length - 1];
    if (line.trim() === '') {
      out.push({ kind: 'p', lines: [] });
      continue;
    }
    const bullet = BULLET.exec(line);
    const numbered = bullet ? null : NUMBERED.exec(line);
    const heading = HEADING.exec(line);
    if (bullet || numbered) {
      const kind = bullet ? 'ul' : 'ol';
      const item = (bullet ?? numbered)![1]!;
      if (last && last.kind === kind) last.items.push(item);
      else out.push({ kind, items: [item] });
    } else if (heading) {
      out.push({ kind: 'h', text: heading[1]! });
    } else if (last && last.kind === 'p') {
      last.lines.push(line);
    } else {
      out.push({ kind: 'p', lines: [line] });
    }
  }
  return out.filter((b) => b.kind !== 'p' || b.lines.length > 0);
}

export function AnswerText({ text }: { text: string }) {
  return (
    <div className="flex flex-col gap-2 leading-relaxed">
      {blocks(text).map((block, i) => {
        if (block.kind === 'h') {
          return (
            <p key={i} className="m-0 font-semibold">
              {inline(block.text)}
            </p>
          );
        }
        if (block.kind === 'p') {
          return (
            <p key={i} className="m-0">
              {block.lines.map((line, j) => (
                <Fragment key={j}>
                  {j > 0 && <br />}
                  {inline(line)}
                </Fragment>
              ))}
            </p>
          );
        }
        const List = block.kind;
        return (
          <List key={i} className={`m-0 pl-5 ${List === 'ul' ? 'list-disc' : 'list-decimal'}`}>
            {block.items.map((item, j) => (
              <li key={j}>{inline(item)}</li>
            ))}
          </List>
        );
      })}
    </div>
  );
}
```

```ts
'use client';

import { useEffect, useState } from 'react';
import type { Run, RunMessage } from '@/lib/agents-api';
import { openRunStream, type EventSourceFactory } from '@/lib/run-stream';
import { mergeMessages } from '@/lib/transcript';

export type RunStreamState = 'idle' | 'connecting' | 'live' | 'ended' | 'error';

export interface RunStreamView {
  run: Run | null;
  messages: RunMessage[];
  state: RunStreamState;
}

const IDLE: RunStreamView = { run: null, messages: [], state: 'idle' };
const CONNECTING: RunStreamView = { run: null, messages: [], state: 'connecting' };

/**
 * Follows one run live: its record and its transcript, as the server streams
 * them. A chat run's stream stays open between turns; it ends with the run.
 * Pass null to follow nothing.
 */
export function useRunStream(
  runId: string | null,
  opts: { createEventSource?: EventSourceFactory } = {},
): RunStreamView {
  // Keyed by run, so switching runs starts from empty without resetting state
  // inside the effect.
  const [view, setView] = useState<RunStreamView & { runId: string | null }>({
    ...IDLE,
    runId: null,
  });
  const { createEventSource } = opts;

  useEffect(() => {
    if (!runId) return;
    const update = (change: (v: RunStreamView) => Partial<RunStreamView>) =>
      setView((current) => {
        const base = current.runId === runId ? current : { ...CONNECTING, runId };
        return { ...base, ...change(base) };
      });
    const live = (v: RunStreamView) => (v.state === 'ended' ? v.state : 'live');
    return openRunStream(
      runId,
      {
        onRun: (run) => update((v) => ({ run, state: live(v) })),
        onMessage: (message) =>
          update((v) => ({ messages: mergeMessages(v.messages, [message]), state: live(v) })),
        onEnd: () => update(() => ({ state: 'ended' })),
        onError: () => update(() => ({ state: 'error' })),
      },
      { createEventSource },
    );
  }, [runId, createEventSource]);

  if (!runId) return IDLE;
  if (view.runId !== runId) return CONNECTING;
  return { run: view.run, messages: view.messages, state: view.state };
}
```

```ts
    refetchInterval: 30_000,
    retry: false,

    staleTime: 60_000,
    select: (data) => data.tools,
  });
}

    queryKey: ['agents', 'list', opts.includeArchived ?? false],

    queryKey: ['agents', 'detail', id],
```

```tsx
'use client';

// Tools and permissions: one row per service, a three-way control per effect
// (Off, Allow, Ask; Delete offers Off and Ask only). A row expands to per-tool
// overrides, where Default falls back to the service's setting.
import { useState } from 'react';
import { SegmentedControl } from '@ship-it-ui/ui';
import type {
  AgentDefinition,
  GrantPolicy,
  ServiceGrants,
  ToolEffect,
  ToolInfo,
} from '@/lib/agents-api';

type Grants = AgentDefinition['grants'];

const EFFECTS: ToolEffect[] = ['read', 'write', 'delete'];
const EFFECT_LABEL: Record<ToolEffect, string> = { read: 'Read', write: 'Write', delete: 'Delete' };
const POLICY_LABEL: Record<GrantPolicy, string> = { off: 'Off', allow: 'Allow', ask: 'Ask' };
const EFFECTIVE_LABEL: Record<GrantPolicy, string> = {
  off: 'Off',
  allow: 'Allowed',
  ask: 'Asks first',
};

const NO_GRANTS: ServiceGrants = { read: 'off', write: 'off', delete: 'off' };

function policyOptions(effect: ToolEffect) {
  const policies: GrantPolicy[] = effect === 'delete' ? ['off', 'ask'] : ['off', 'allow', 'ask'];
  return policies.map((p) => ({ value: p, label: POLICY_LABEL[p] }));
}

function servicePolicy(grants: Grants, service: string, effect: ToolEffect): GrantPolicy {
  return grants.services[service]?.[effect] ?? 'off';
}

export interface GrantsMatrixProps {
  grants: Grants;
  /** The tool catalog (GET /api/tools). */
  tools: ReadonlyArray<ToolInfo>;
  onChange(grants: Grants): void;
  disabled?: boolean;
}

export function GrantsMatrix({ grants, tools, onChange, disabled }: GrantsMatrixProps) {
  const [open, setOpen] = useState<ReadonlySet<string>>(new Set());
  const services = [...new Set(tools.map((t) => t.service))].sort();

  const setService = (service: string, effect: ToolEffect, policy: GrantPolicy) =>
    onChange({
      ...grants,
      services: {
        ...grants.services,
        [service]: { ...NO_GRANTS, ...grants.services[service], [effect]: policy } as ServiceGrants,
      },
    });

  const setTool = (toolId: string, policy: GrantPolicy | 'default') => {
    const next = { ...grants.tools };
    if (policy === 'default') delete next[toolId];
    else next[toolId] = policy;
    onChange({ ...grants, tools: next });
  };

  const toggle = (service: string) =>
    setOpen((prev) => {
      const next = new Set(prev);
      if (next.has(service)) next.delete(service);
      else next.add(service);
      return next;
    });

  return (
    <div className="flex flex-col gap-2">
      <div className="border-border rounded-base divide-border divide-y border">
        {services.map((service) => {
          const serviceTools = tools.filter((t) => t.service === service);
          const expanded = open.has(service);
          return (
            <div key={service} className="flex flex-col">
              <div className="flex flex-wrap items-center gap-4 px-3 py-2">
                <button
                  type="button"
                  className="text-text flex min-w-40 items-center gap-2 text-left text-[13px] font-medium"
                  aria-expanded={expanded}
                  onClick={() => toggle(service)}
                >
                  <span aria-hidden>{expanded ? '▾' : '▸'}</span>
                  <span>{service}</span>
                  <span className="text-text-muted font-normal">
                    {serviceTools.length} {serviceTools.length === 1 ? 'tool' : 'tools'}
                  </span>
                </button>
                {EFFECTS.map((effect) =>
                  serviceTools.some((t) => t.effect === effect) ? (
                    <div key={effect} className="flex items-center gap-2 text-[12px]">
                      <span className="text-text-muted">{EFFECT_LABEL[effect]}</span>
                      <SegmentedControl
                        size="sm"
                        aria-label={`${service} ${effect}`}
                        options={policyOptions(effect)}
                        value={servicePolicy(grants, service, effect)}
                        onValueChange={(v) => setService(service, effect, v as GrantPolicy)}
                        disabled={disabled}
                      />
                    </div>
                  ) : null,
                )}
              </div>
              {expanded && (
```

```ts
// What publishing would change: the draft against the published version,
// field by field, for the publish dialog.
import type { AgentDefinition, AgentLimits, ServiceGrants, ToolEffect } from './agents-api';

export interface DefinitionChange {
  field: string;
  before: string;
  after: string;
}

const LIMIT_LABEL: Record<keyof AgentLimits, string> = {
  maxSteps: 'Max steps',
  maxTokens: 'Max tokens per run',
  timeoutSeconds: 'Timeout (seconds)',
  dailyTokens: 'Daily tokens',
};

const EFFECTS: ToolEffect[] = ['read', 'write', 'delete'];
const OFF: ServiceGrants = { read: 'off', write: 'off', delete: 'off' };

export function definitionDiff(
  published: AgentDefinition | null,
  draft: AgentDefinition,
): DefinitionChange[] {
  const changes: DefinitionChange[] = [];
  const add = (field: string, before: string, after: string) => {
    if (before !== after) changes.push({ field, before, after });
  };

  add('Instructions', published?.instructions ?? '', draft.instructions);
  add('Model', published?.model ?? '', draft.model);
  add('Effort', published ? (published.effort ?? 'default') : '', draft.effort ?? 'default');
  for (const key of Object.keys(LIMIT_LABEL) as Array<keyof AgentLimits>) {
    add(
      LIMIT_LABEL[key],
      published ? String(published.limits[key]) : '',
      String(draft.limits[key]),
    );
  }

  const before = published?.grants ?? { services: {}, tools: {} };
  const services = [
    ...new Set([...Object.keys(before.services), ...Object.keys(draft.grants.services)]),
  ].sort();
  for (const service of services) {
    const was = before.services[service] ?? OFF;
    const now = draft.grants.services[service] ?? OFF;
    for (const effect of EFFECTS) add(`${service} ${effect}`, was[effect], now[effect]);
  }
  const tools = [
    ...new Set([...Object.keys(before.tools), ...Object.keys(draft.grants.tools)]),
  ].sort();
  for (const tool of tools) {
    add(
      tool,
      before.tools[tool] ?? 'service default',
      draft.grants.tools[tool] ?? 'service default',
    );
  }

  add(
    'Output schema',
    published?.output.schema ? JSON.stringify(published.output.schema) : 'none',
    draft.output.schema ? JSON.stringify(draft.output.schema) : 'none',
  );
  return changes;
}
```

```tsx
'use client';

// Publishing is explicit: it shows what changes against the published
// version, then makes the draft the version runs and triggers use.
import { useState } from 'react';
import { Button, Dialog, Field, Input } from '@ship-it-ui/ui';
import type { AgentDefinition, AgentVersion } from '@/lib/agents-api';
import { definitionDiff } from '@/lib/definition-diff';

export interface PublishDialogProps {
  open: boolean;
  onOpenChange(open: boolean): void;
  /** The version runs use now; null before the first publish. */
  published: AgentVersion | null;
  /** The saved draft. */
  draft: AgentDefinition;
  pending: boolean;
  onConfirm(note: string): void;
}

function clip(text: string): string {
  return text.length > 400 ? `${text.slice(0, 400)}…` : text;
}

export function PublishDialog({
  open,
  onOpenChange,
  published,
  draft,
  pending,
  onConfirm,
}: PublishDialogProps) {
  const [note, setNote] = useState('');
  const changes = definitionDiff(published?.definition ?? null, draft);
  const next = (published?.version ?? 0) + 1;

  return (
    <Dialog
      open={open}
      onOpenChange={onOpenChange}
      title={`Publish v${next}`}
      description={
        published
          ? `Compared with v${published.version}, the version runs use now.`
          : 'First version: runs will use this definition.'
      }
      width={680}
      footer={
        <div className="flex justify-end gap-2">
          <Button variant="outline" size="sm" onClick={() => onOpenChange(false)}>
            Cancel
          </Button>
          <Button
            size="sm"
            loading={pending}
            disabled={pending || (published !== null && changes.length === 0)}
            onClick={() => onConfirm(note)}
          >
            {`Publish v${next}`}
          </Button>
        </div>
      }
    >
      <div className="flex flex-col gap-4">
        {published !== null && changes.length === 0 ? (
          <p className="text-text-muted m-0 text-[13px]">
            The draft is the same as v{published.version}.
          </p>
        ) : (
          <div className="max-h-80 overflow-auto">
            <table className="w-full border-collapse text-[12px]">
              <thead>
                <tr className="text-text-muted text-left">
                  <th className="py-1 pr-3 font-medium">Field</th>
                  <th className="py-1 pr-3 font-medium">
                    {published ? `v${published.version}` : 'Before'}
                  </th>
                  <th className="py-1 font-medium">Draft</th>
                </tr>
              </thead>
              <tbody>
                {changes.map((c) => (
                  <tr key={c.field} className="border-border border-t align-top">
                    <th scope="row" className="text-text py-1 pr-3 text-left font-medium">
                      {c.field}
                    </th>
                    <td className="text-text-muted py-1 pr-3 font-mono whitespace-pre-wrap">
                      {clip(c.before)}
                    </td>
                    <td className="text-text py-1 font-mono whitespace-pre-wrap">
                      {clip(c.after)}
                    </td>
                  </tr>
                ))}
              </tbody>
            </table>
          </div>
        )}
        <Field label="Note (optional)" hint="Shown in the version history.">
          {(p) => (
            <Input {...p} value={note} maxLength={500} onChange={(e) => setNote(e.target.value)} />
          )}
        </Field>
      </div>
    </Dialog>
  );
}
```

```tsx
'use client';

// The agent editor (/ai/agents/new, /ai/agents/[id]). Saves are drafts,
// guarded by the agent's revision (If-Match): a save over someone else's is
// refused and offers a reload. Publishing is explicit and shows what changes.
import { useState, type ReactNode } from 'react';
import { useRouter } from 'next/navigation';
import { useQueryClient } from '@tanstack/react-query';
import {
  Badge,
  Banner,
  Button,
  Dialog,
  EmptyState,
  Spinner,
  Tab,
  Tabs,
  TabsContent,
  TabsList,
} from '@ship-it-ui/ui';
import { IconGlyph } from '@ship-it-ui/icons';
import {
  AgentApiError,
  archiveAgent,
  createAgent,
  publishAgent,
  updateAgent,
  type Agent,
  type ModelInfo,
  type ToolInfo,
} from '@/lib/agents-api';
import { hasCapability, useCurrentUser } from '@/lib/current-user';
import { useAgent, useAgentVersions, useModels, useTools } from '@/lib/hooks/use-agents';
import { AgentForm, newAgentValue, type AgentFormValue } from './agent-form';
import { AgentRuns, AgentVersions } from './agent-tabs';
import { PublishDialog } from './publish-dialog';

function formValueOf(agent: Agent): AgentFormValue {
  return {
    slug: agent.slug,
    name: agent.name,
    description: agent.description,
    enabled: agent.enabled,
    definition: agent.draftDefinition,
  };
}

// Key order differs between what the server sends and what the form builds.
function stable(value: unknown): string {
  return JSON.stringify(value, (_key, v: unknown) =>
    v && typeof v === 'object' && !Array.isArray(v)
      ? Object.fromEntries(
          Object.entries(v as Record<string, unknown>).sort(([a], [b]) => a.localeCompare(b)),
        )
      : v,
  );
}

type Notice = { tone: 'ok' | 'err' | 'warn'; text: string } | null;

export function AgentEditor({
  agentId,
  aside,
}: {
  agentId: string | null;
  aside?: (agent: Agent) => ReactNode;
}) {
  const models = useModels();
  const tools = useTools();
  const agent = useAgent(agentId);
  // Bumped by Reload so the form starts over from the server's copy.
  const [loadKey, setLoadKey] = useState(0);

  if (models.isPending || tools.isPending || (agentId !== null && agent.isPending)) {
    return (
      <div className="grid place-items-center p-12">
        <Spinner label="Loading agent" />
      </div>
    );
  }
  if (agent.isError) {
    const notFound = agent.error instanceof AgentApiError && agent.error.status === 404;
    return (
      <div className="mx-auto max-w-2xl p-6">
        <EmptyState
          titleAs="h1"
          icon={<IconGlyph name="bot" />}
          title={notFound ? 'Agent not found' : 'Could not load the agent'}
          description={notFound ? 'It may have been archived.' : agent.error.message}
        />
      </div>
    );
  }
  if (models.isError || tools.isError) {
    return (
      <div className="mx-auto max-w-2xl p-6">
        <Banner tone="err">{(models.error ?? tools.error)?.message}</Banner>
      </div>
    );
  }
  return (
    <EditorBody
      key={`${agentId ?? 'new'}:${loadKey}`}
      agent={agent.data ?? null}
      defaultModel={models.data.defaultModel}
      models={models.data.models}
      tools={tools.data}
      aside={aside}
      onReload={async () => {
        await agent.refetch();
        setLoadKey((k) => k + 1);
      }}
    />
  );
}

function EditorBody({
  agent,
  defaultModel,
  models,
  tools,
  aside,
  onReload,
}: {
  agent: Agent | null;
  defaultModel: string;
  models: ReadonlyArray<ModelInfo>;
  tools: ReadonlyArray<ToolInfo>;
  aside?: (agent: Agent) => ReactNode;
  onReload(): Promise<void>;
}) {
  const router = useRouter();
  const queryClient = useQueryClient();
  const canWrite = hasCapability(useCurrentUser(), 'agents:write');

  const [base, setBase] = useState<Agent | null>(agent);
  const [value, setValue] = useState<AgentFormValue>(
    agent ? formValueOf(agent) : newAgentValue(defaultModel),
  );
  const [issues, setIssues] = useState<Record<string, string>>({});
  const [notice, setNotice] = useState<Notice>(null);
  const [conflict, setConflict] = useState<number | null>(null);
  const [busy, setBusy] = useState<'save' | 'publish' | 'archive' | null>(null);
  const [publishOpen, setPublishOpen] = useState(false);
  const [archiveOpen, setArchiveOpen] = useState(false);
  const versions = useAgentVersions(base?.id ?? null);

  const dirty = base === null || stable(formValueOf(base)) !== stable(value);
  const published = versions.data?.find((v) => v.version === base?.publishedVersion) ?? null;

  const saved = (next: Agent, text: string) => {
    setBase(next);
    setValue(formValueOf(next));
    setIssues({});
    setConflict(null);
    setNotice({ tone: 'ok', text });
    queryClient.setQueryData(['agents', 'detail', next.id], next);
    void queryClient.invalidateQueries({ queryKey: ['agents', 'list'] });
  };

  const failed = (err: unknown) => {
    if (err instanceof AgentApiError && err.code === 'VERSION_CONFLICT') {
      setConflict(err.serverRevision ?? null);
      setNotice(null);
      return;
    }
    if (err instanceof AgentApiError && err.issues) {
      setIssues(
        Object.fromEntries(
          err.issues.map((i) => [
            i.path.startsWith('definition.grants') ? 'definition.grants' : i.path,
            i.message,
          ]),
        ),
      );
    }
    setNotice({ tone: 'err', text: err instanceof Error ? err.message : String(err) });
  };

  const save = async () => {
    setBusy('save');
    try {
      if (base === null) {
        const created = await createAgent({
          slug: value.slug,
          name: value.name,
          description: value.description,
          definition: value.definition,
        });
        queryClient.setQueryData(['agents', 'detail', created.id], created);
        void queryClient.invalidateQueries({ queryKey: ['agents', 'list'] });
        router.replace(`/ai/agents/${created.id}`);
        return;
      }
      const next = await updateAgent(base.id, base.revision, {
        name: value.name,
        description: value.description,
        enabled: value.enabled,
        definition: value.definition,
      });
      saved(next, 'Draft saved.');
    } catch (err) {
      failed(err);
    } finally {
      setBusy(null);
    }
  };

  const publish = async (note: string) => {
    if (!base) return;
    setBusy('publish');
    try {
      const result = await publishAgent(base.id, base.revision, note.trim() || undefined);
      setPublishOpen(false);
      saved(result.agent, `Published v${result.version.version}.`);
      void queryClient.invalidateQueries({ queryKey: ['agents', 'versions', base.id] });
    } catch (err) {
      setPublishOpen(false);
      failed(err);
    } finally {
      setBusy(null);
    }
  };

  const archive = async () => {
    if (!base) return;
    setBusy('archive');
    try {
      await archiveAgent(base.id, base.revision);
      void queryClient.invalidateQueries({ queryKey: ['agents', 'list'] });
      router.push('/ai/agents');
    } catch (err) {
      setArchiveOpen(false);
      failed(err);
    } finally {
      setBusy(null);
    }
  };

  const form = (
    <AgentForm
      value={value}
      onChange={(next) => {
        setValue(next);
        // Validation messages describe what was last sent, not what is typed now.
        setIssues({});
        setNotice((current) => (current?.tone === 'err' ? null : current));
      }}
      models={models}
      tools={tools}
      isNew={base === null}
      readOnly={!canWrite}
      issues={issues}
    />
  );

  return (
    <div className="mx-auto flex max-w-7xl flex-col gap-4 p-6">
      <header className="flex flex-wrap items-start justify-between gap-4">
        <div className="flex flex-col gap-1">
          <h1 className="text-text m-0 flex items-center gap-2 text-[22px] font-semibold tracking-tight">
            {base ? base.name : 'New agent'}
            {base?.builtin && (
              <Badge variant="accent" size="sm">
                Built-in
              </Badge>
            )}
          </h1>
          <p className="text-text-muted m-0 flex items-center gap-2 text-[12px]">
            {base === null
              ? 'Create the agent, then test and publish it.'
              : base.publishedVersion === null
                ? 'Not published: only test runs can use it.'
                : `Runs use v${base.publishedVersion}.`}
            {base !== null && dirty && (
              <Badge variant="warn" size="sm">
                Unsaved changes
              </Badge>
            )}
          </p>
        </div>
        {canWrite && (
          <div className="flex items-center gap-2">
            {base !== null && !base.builtin && (
              <Button variant="ghost" size="sm" onClick={() => setArchiveOpen(true)}>
                Archive…
              </Button>
            )}
            {base !== null && (
              <Button
                variant="outline"
                size="sm"
                disabled={
                  dirty || busy !== null || (base.publishedVersion !== null && !versions.data)
                }
                title={dirty ? 'Save your changes before publishing' : undefined}
                onClick={() => setPublishOpen(true)}
              >
                Publish…
              </Button>
            )}
            <Button
              size="sm"
              loading={busy === 'save'}
              disabled={!dirty || busy !== null}
              onClick={() => void save()}
            >
              {base === null ? 'Create agent' : 'Save draft'}
            </Button>
          </div>
        )}
      </header>

      {conflict !== null && (
        <Banner
          tone="warn"
          icon={<IconGlyph name="warn" />}
          action={
            <Button size="sm" variant="outline" onClick={() => void onReload()}>
              Reload
            </Button>
          }
        >
          Someone else saved this agent since you opened it
          {conflict ? ` (it is now at revision ${conflict})` : ''}. Reload to see their version;
          your unsaved changes will be lost.
        </Banner>
      )}
      {notice && (
        <Banner tone={notice.tone}>
          <span className="min-w-0 [overflow-wrap:anywhere]">{notice.text}</span>
        </Banner>
      )}

      <div className="grid grid-cols-1 gap-6 xl:grid-cols-[minmax(0,1fr)_420px]">
        <div className="min-w-0">
          {base === null ? (
            form
          ) : (
            <Tabs defaultValue="definition" variant="pill">
              <TabsList className="w-fit">
                <Tab value="definition">Definition</Tab>
                <Tab value="runs">Runs</Tab>
                <Tab value="versions">Versions</Tab>
              </TabsList>
              <TabsContent value="definition" className="mt-4">
                {form}
              </TabsContent>
              <TabsContent value="runs" className="mt-4">
                <AgentRuns agentId={base.id} />
              </TabsContent>
              <TabsContent value="versions" className="mt-4">
                <AgentVersions agentId={base.id} publishedVersion={base.publishedVersion} />
              </TabsContent>
            </Tabs>
          )}
        </div>
        {base !== null && aside && (
          // Stays in view while the form scrolls, so a change can be tried at once.
          <aside className="min-w-0 xl:sticky xl:top-4 xl:self-start">{aside(base)}</aside>
        )}
      </div>

      {base !== null && publishOpen && (
        <PublishDialog
          open
          onOpenChange={setPublishOpen}
          published={published}
          draft={base.draftDefinition}
          pending={busy === 'publish'}
          onConfirm={(note) => void publish(note)}
        />
      )}
      {base !== null && (
        <Dialog
          open={archiveOpen}
          onOpenChange={setArchiveOpen}
          title={`Archive ${base.name}?`}
          description="It stops running and leaves the agent list. Its runs and versions are kept."
          footer={
            <div className="flex justify-end gap-2">
              <Button variant="outline" size="sm" onClick={() => setArchiveOpen(false)}>
                Cancel
              </Button>
              <Button
                variant="destructive"
                size="sm"
                loading={busy === 'archive'}
                onClick={() => void archive()}
              >
                Archive agent
              </Button>
            </div>
          }
        />
      )}
    </div>
  );
}
```

```tsx
'use client';

// A conversation with one agent: the first question starts a chat run, later
// ones go to the same run while it waits for input. Used by Ask (published
// agents) and by the editor's test panel (the saved draft).
import { useMemo, useState } from 'react';
import Link from 'next/link';
import { Banner, Button } from '@ship-it-ui/ui';
import { AskBar } from '@ship-it-ui/shipit';
import {
  AgentApiError,
  cancelRun,
  sendRunMessage,
  startRun,
  TERMINAL_RUN_STATUSES,
} from '@/lib/agents-api';
import { useRunStream } from '@/lib/hooks/use-run-stream';
import type { EventSourceFactory } from '@/lib/run-stream';
import { buildTranscript } from '@/lib/transcript';
import { RunTranscript } from './run-transcript';

export interface AgentChatProps {
  agentId: string;
  /** Run the agent's saved draft instead of its published version. */
  draft?: boolean;
  placeholder?: string;
  emptyText?: string;
  userInitial?: string;
  /** Tests inject a fake; browsers use EventSource. */
  createEventSource?: EventSourceFactory;
}

function describe(err: unknown): string {
  if (err instanceof AgentApiError && err.checks?.length) {
    return `${err.message} ${err.checks
      .filter((c) => !c.ok)
      .map((c) => c.detail)
      .join(' ')}`;
  }
  return err instanceof Error ? err.message : String(err);
}

export function AgentChat({
  agentId,
  draft = false,
  placeholder = 'Ask a question…',
  emptyText,
  userInitial,
  createEventSource,
}: AgentChatProps) {
  const [runId, setRunId] = useState<string | null>(null);
  const [text, setText] = useState('');
  const [sending, setSending] = useState(false);
  const [error, setError] = useState<string | null>(null);
  const stream = useRunStream(runId, { createEventSource });
  const items = useMemo(() => buildTranscript(stream.messages), [stream.messages]);

  const run = stream.run;
  const finished = run !== null && TERMINAL_RUN_STATUSES.has(run.status);
  const working =
    sending ||
    (runId !== null &&
      stream.state !== 'error' &&
      (run === null || run.status === 'queued' || run.status === 'running'));

  const submit = async (input: string) => {
    setError(null);
    setSending(true);
    try {
      if (runId === null || finished) {
        const started = await startRun(agentId, { input, mode: 'chat', draft });
        setRunId(started.id);
      } else {
        await sendRunMessage(runId, input);
      }
      setText('');
    } catch (err) {
      setError(describe(err));
    } finally {
      setSending(false);
    }
  };

  const stop = async () => {
    if (!runId) return;
    try {
      await cancelRun(runId);
    } catch (err) {
      setError(describe(err));
    }
  };

  const reset = () => {
    setRunId(null);
    setError(null);
  };

  return (
    <div className="flex flex-col gap-4">
      {runId !== null && (
        <div className="flex items-center justify-between text-[12px]">
          <Link href={`/ai/runs/${runId}`} className="text-accent hover:underline">
            Open run
          </Link>
          <Button variant="ghost" size="sm" onClick={reset}>
            New conversation
          </Button>
        </div>
      )}

      <RunTranscript
        items={items}
        streaming={working}
        userInitial={userInitial}
        emptyText={emptyText}
      />

      {run?.status === 'failed' && (
        // Error text can be one long unbroken string (a provider's raw message).
        <Banner tone="err">
          <span className="min-w-0 [overflow-wrap:anywhere]">
            {run.error?.message || 'The run failed.'}
          </span>
        </Banner>
      )}
      {run?.status === 'cancelled' && <Banner tone="warn">The run was stopped.</Banner>}
      {stream.state === 'error' && (
        <Banner tone="warn">Live updates stopped. Open the run to see where it got to.</Banner>
      )}
      {error && (
        <Banner tone="err">
          <span className="min-w-0 [overflow-wrap:anywhere]">{error}</span>
        </Banner>
      )}

      <div className="flex flex-col gap-2">
        <AskBar
          value={text}
          onValueChange={setText}
          onSubmit={(value) => void submit(value)}
          placeholder={placeholder}
          disabled={working}
          streaming={working}
          maxWidth="100%"
        />
        {working && runId !== null && (
          <div>
            <Button
              variant="outline"
              size="sm"
              disabled={run?.cancelRequested}
              onClick={() => void stop()}
            >
              Stop
            </Button>
          </div>
        )}
      </div>
    </div>
  );
}
```

```tsx
'use client';

// One run (/ai/runs/[id]): who ran which agent version, how it went and what
// it cost, then the transcript with every tool call's audit detail. A run
// that is still going is followed live.
import { useMemo, useState, type ReactNode } from 'react';
import Link from 'next/link';
import { Banner, Button, EmptyState, Spinner } from '@ship-it-ui/ui';
import { IconGlyph } from '@ship-it-ui/icons';
import { AgentApiError, cancelRun, TERMINAL_RUN_STATUSES, type Run } from '@/lib/agents-api';
import { hasCapability, useCurrentUser } from '@/lib/current-user';
import { useAgent, useRun, useRunTranscript } from '@/lib/hooks/use-agents';
import { useRunStream } from '@/lib/hooks/use-run-stream';
import type { EventSourceFactory } from '@/lib/run-stream';
import { buildTranscript, mergeMessages } from '@/lib/transcript';
import { RunStatusBadge } from './run-status-badge';
import { RunTranscript } from './run-transcript';

function duration(run: Run): string {
  if (!run.startedAt) return 'not started';
  if (!run.finishedAt) return 'still going';
  const ms = Date.parse(run.finishedAt) - Date.parse(run.startedAt);
  if (ms < 1000) return `${ms} ms`;
  if (ms < 60_000) return `${(ms / 1000).toFixed(1)} s`;
  return `${Math.floor(ms / 60_000)} min ${Math.round((ms % 60_000) / 1000)} s`;
}

function Fact({ label, children }: { label: string; children: ReactNode }) {
  return (
    <div className="flex flex-col">
      <dt className="text-text-muted text-[11px] tracking-wide uppercase">{label}</dt>
      <dd className="text-text m-0 text-[13px]">{children}</dd>
    </div>
  );
}

export function RunView({
  runId,
  createEventSource,
}: {
  runId: string;
  /** Tests inject a fake; browsers use EventSource. */
  createEventSource?: EventSourceFactory;
}) {
  const user = useCurrentUser();
  const loaded = useRun(runId);
  const hidden = loaded.data?.contentHidden === true;
  const readable = loaded.data !== undefined && !hidden;
  // A finished run is read once; one that is still going is followed.
  const live = readable && !TERMINAL_RUN_STATUSES.has(loaded.data.status);
  const stream = useRunStream(live ? runId : null, { createEventSource });
  const stored = useRunTranscript(readable ? runId : null, stream.messages.length);
  const agent = useAgent(loaded.data?.agentId ?? null);
  const [stopError, setStopError] = useState<string | null>(null);

  const items = useMemo(
    () =>
      buildTranscript(
        mergeMessages(stored.data?.messages ?? [], stream.messages),
        stored.data?.toolCalls ?? [],
      ),
    [stored.data, stream.messages],
  );

  if (loaded.isPending) {
    return (
      <div className="grid place-items-center p-12">
        <Spinner label="Loading run" />
      </div>
    );
  }
  if (loaded.isError) {
    const notFound = loaded.error instanceof AgentApiError && loaded.error.status === 404;
    return (
      <div className="mx-auto max-w-2xl p-6">
        <EmptyState
          titleAs="h1"
          icon={<IconGlyph name="activity" />}
          title={notFound ? 'Run not found' : 'Could not load the run'}
          description={notFound ? undefined : loaded.error.message}
        />
      </div>
    );
  }

  const run = stream.run ?? loaded.data;
  const finished = TERMINAL_RUN_STATUSES.has(run.status);
  const canStop =
    !finished &&
    hasCapability(user, 'agents:run') &&
    (run.triggeredBy === user.email || hasCapability(user, '*'));

  const stop = async () => {
    setStopError(null);
    try {
      await cancelRun(run.id);
    } catch (err) {
      setStopError(err instanceof Error ? err.message : String(err));
    }
  };

  return (
    <div className="mx-auto flex max-w-4xl flex-col gap-6 p-6">
      <header className="flex flex-wrap items-start justify-between gap-4">
        <div className="flex flex-col gap-1">
          <h1 className="text-text m-0 flex items-center gap-3 text-[22px] font-semibold tracking-tight">
            Run
            <RunStatusBadge status={run.status} />
          </h1>
          <p className="text-text-muted m-0 font-mono text-[12px]">{run.id}</p>
        </div>
        {canStop && (
          <Button
            variant="outline"
            size="sm"
            disabled={run.cancelRequested}
            onClick={() => void stop()}
          >
            {run.cancelRequested ? 'Stopping…' : 'Stop run'}
          </Button>
        )}
      </header>

      <dl className="border-border rounded-base m-0 grid grid-cols-2 gap-4 border p-4 sm:grid-cols-4">
        <Fact label="Agent">
          <Link href={`/ai/agents/${run.agentId}`} className="text-accent hover:underline">
            {agent.data?.name ?? 'Agent'}
          </Link>
        </Fact>
        <Fact label="Version">
          {run.agentVersion === null ? (
            'Draft'
          ) : (
            <span className="font-mono">v{run.agentVersion}</span>
          )}
        </Fact>
        <Fact label="Started by">{run.triggeredBy}</Fact>
        <Fact label="Trigger">{run.triggerKind}</Fact>
        <Fact label="Started">{new Date(run.createdAt).toLocaleString()}</Fact>
        <Fact label="Duration">{duration(run)}</Fact>
        <Fact label="Tokens">
          <span
            title={`${run.inputTokens.toLocaleString()} in, ${run.outputTokens.toLocaleString()} out`}
          >
            {(run.inputTokens + run.outputTokens).toLocaleString()}
          </span>
        </Fact>
        <Fact label="Model steps">{run.steps}</Fact>
      </dl>

      {run.status === 'failed' && (
        <Banner tone="err" icon={<IconGlyph name="warn" />}>
          <span className="min-w-0 [overflow-wrap:anywhere]">
            {run.error?.message ||
              (run.error ? `The run failed (${run.error.code}).` : 'The run failed.')}
          </span>
        </Banner>
      )}
      {run.status === 'waiting_input' && (
        <Banner tone="accent">
          This conversation is waiting for a reply where it was started.
        </Banner>
      )}
      {stopError && <Banner tone="err">{stopError}</Banner>}
      {stream.state === 'error' && (
        <Banner tone="warn">Live updates stopped. Reload the page to see the latest.</Banner>
      )}
      {run.warnings.length > 0 && (
        <ul className="text-text-muted m-0 flex list-disc flex-col gap-1 pl-5 text-[12px]">
          {run.warnings.map((warning) => (
            <li key={warning}>{warning}</li>
          ))}
        </ul>
      )}

      {hidden ? (
        <Banner tone="accent">
          You can see that this run happened, but not what was in it. A run&apos;s content is shown
          to the person who started it, the agent&apos;s author and admins.
        </Banner>
      ) : stored.isError ? (
        <Banner tone="err">{stored.error.message}</Banner>
      ) : (
        <RunTranscript
          items={items}
          detail="full"
          streaming={!finished && run.status !== 'waiting_input'}
          userInitial={run.triggeredBy.charAt(0).toUpperCase()}
          emptyText={stored.isPending ? 'Loading the transcript…' : 'Nothing in this run yet.'}
        />
      )}
    </div>
  );
}
```

## Self-review notes

- **Spec coverage (Milestone 1, UI):** agents list, `/ai/agents/new` and `/ai/agents/[id]` (Tasks 4, 6); editor sections Identity, Instructions, Model and limits, Tools and permissions, Output (Tasks 5, 6); draft saves with the ETag pattern and explicit Publish with a diff (Task 6); tabs Definition, Runs, Versions (Task 6); test panel and Ask on `AskBar`, `CopilotMessage`, `ReasoningBlock` and `ToolCallCard` (Tasks 3, 7); the run view with every tool call's service, effect, policy, decision and duration and a collapsible input and output (Task 8); `GET /tools` (Task 1); empty and off states from `GET /ai/status` (Task 4); Ask defaults to the built-in assistant (Task 7).
- **Not in this plan, on purpose:**
  - **Triggers tab** (Milestone 2), **approval cards** and "who approved" in the transcript (Milestone 3: `ask` tools are not offered until then, and the matrix says so), the **Activity** runs list and the **Tools** page (Milestones 2 and 3; they stay placeholders, and a run's page is reached from the agent's Runs tab or a chat's Open run link).
  - **Output** is a section with a sentence, not a schema editor: structured output is deferred to the workflows milestone by the runner plan.
  - **`Citation`**: runs carry no citation data yet.
  - **Owner team**: the API has `ownerTeamId`; the form does not offer it until the graph projection (Milestone 5) gives it a use.
  - **Text deltas**: the runner sends whole messages, so answers appear a message at a time.
- **Deviations from the spec, each pinned by a test:**
  - **Markdown** in answers is a small renderer (paragraphs, lists, headings, bold, inline code) built as React elements, not a library: no new dependency, and nothing can reach the page as HTML.
  - **Delete** in the matrix offers Off and Ask only, as the spec says; **Ask** is offered but labelled as not yet effective.
- **Found along the way:**
  - **CORS on `main`** allowed only `GET`, `HEAD` and `POST` and hid `ETag`, so in local dev no existing save, edit or delete worked from the browser, and the schema and connector editors never sent `If-Match`. Fixed in Task 1.
  - **`pnpm start:all`** could not start on the branch (13 dev tasks, turbo allows 9 by default). Fixed on the branch in `4447981` before this plan.
  - **A model-auth failure** shows the provider's raw JSON as the run's error. The UI wraps it so it cannot widen the page; a plain sentence is a server-side change, listed with the runner's deferred minors.
- **`seed:reset` is unchanged.** It wipes connector and graph state and keeps configuration and audit data; agents, versions and runs are the latter.
